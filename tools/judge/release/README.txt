불만족 평가 피드백 자동분류 (실행 파일 1개, 설치 불필요)

[준비, 처음 한 번]
1. Claude Code를 설치하고 한 번 로그인한다. https://claude.com/claude-code
2. 불만족평가_피드백_자동분류_v*.exe 를 바탕화면 등 편한 곳에 둔다.

[매번]
1. 자동분류 exe를 더블클릭하고 Metabase 내보내기 파일을 고른다. (파일을 exe 아이콘 위로 끌어다 놓아도 된다)
2. 검은 창이 끝날 때까지 기다린다. 50건 기준 10~15분.
3. 원본 파일 옆에 생긴 "원본파일명_판정.xlsx"를 대시보드 [데이터 조회] 업로드에 올린다.
4. 불만족 평가 관리에서 판정 필터를 "확인 필요"로 두고 건별로 확인 후 저장한다.

[동작 방식]
처음 실행할 때 exe 안의 판정 도구(프롬프트·스크립트·Node 실행 파일)를
%LOCALAPPDATA%\FeedbackJudge\v<버전>\ 에 풀어 두고 그 폴더에서 Claude Code를 실행한다.
새 버전 exe를 받으면 새 버전 폴더에 따로 풀리므로 이전 것을 지울 필요 없다.
외부 유료 API는 쓰지 않는다. 판정은 내 PC의 Claude Code가 한다.

[문제가 생기면]
검은 창의 메시지를 캡처해 AI 전략팀에 전달한다.
