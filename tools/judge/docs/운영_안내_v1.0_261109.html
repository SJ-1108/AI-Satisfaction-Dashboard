불만족 피드백 자동 판정 운영 안내

대상AI 답변 만족도 대시보드 등록 담당자
적용일2026-11-09 (대시보드 main 배포 완료) · 판정기 v1.2.0 (2026-11-11)
한 줄 요약판정기 exe를 실행해 Metabase 파일을 고르고, 나온 파일을 평소처럼 업로드

1. 무엇이 달라지는지

지금까지는 Metabase 내보내기 파일을 대시보드에 올린 뒤, 불만족 건마다 사람이 원인 분류·유관 부서·처리 상태·피드백 내용을 직접 입력하는 방식.

앞으로는 올리기 전에 판정기 exe로 파일을 한 번 돌리는 단계가 추가됨. 판정 결과가 붙은 파일이 만들어지고, 그 파일을 기존과 같은 업로드 버튼으로 올리면 평가 원본과 피드백이 한 번에 저장됨. 명확한 건은 자동 확정, 애매한 건은 초안만 채워 두고 담당자가 확인.

  • 외부 유료 API 호출 없음. 판정은 내 PC의 Claude Code가 수행
  • DB 변경 없음. 대시보드는 이미 배포 완료
  • 이미 피드백이 있는 건은 덮어쓰지 않음. 같은 파일을 다시 올려도 안전
  • 판정 열이 없는 파일을 올리면 예전과 완전히 동일하게 동작

2. 최초 1회 준비

  • Claude Code 설치 후 한 번 로그인 (claude.com/claude-code)
  • AI 전략팀이 전달한 판정기_v1.2.0.exe 를 바탕화면 등 편한 곳에 두기 (설치 없음, 파일 하나)

처음 실행할 때 exe 안의 판정 도구가 내 PC 로컬 폴더(%LOCALAPPDATA%\FeedbackJudge\v1.2.0)에 자동으로 풀림. 새 버전 exe를 받으면 새 폴더에 따로 풀리므로 이전 것을 지울 필요 없음.

3. 매회 절차

1
Metabase에서 내보내기 파일 다운로드기존과 동일
2
판정기 exe를 더블클릭하고 받은 파일 선택 추가되는 단계 파일을 exe 아이콘 위로 끌어다 놓아도 됨. 검은 창이 열리고 판정이 진행됨. 50건 기준 10~15분. 창을 닫지 말고 기다리기. 끝나면 결과 파일이 있는 폴더와 대시보드 업로드 화면이 자동으로 열림
3
원본 파일 옆에 생긴 원본파일명_판정.xlsx 를 대시보드 데이터 조회 → 업로드에 올리기 미리보기에 "피드백 포함 N"이 보이면 정상. 완료 메시지에 "피드백 N건 등록" 표시
4
불만족 평가 관리 → 판정 필터 확인 필요 → 건별로 열어 초안 확인·수정 후 저장 저장하면 "확인 필요"가 사라지고 담당자명으로 바뀜. 확정(1단) 건은 손댈 필요 없음

4. 대시보드에서 보이는 것

담당자명 칸의미담당자가 할 일
AI 분류규칙상 명확해 자동 확정된 건(1단). 학습과 무관한 질의, 의도 판단 불가, 답변·서비스 범위 벗어남, 자료 부재가 명확한 데이터 없음. 유관 부서 없음없음
AI 분류 확인 필요애매한 건(2단). 원인 분류·부서·상태·피드백 내용 초안이 채워져 있고 담당자 확인 전. 모달 상단에 확인 포인트 표시초안 확인·수정 후 저장
담당자명사람이 직접 작성했거나, 확인 필요 건을 확인·저장한 건없음

판정 필터: 전체 / 확인 필요 / AI 분류 확정(1단) / AI 분류 전체 / 담당자 작성. 작업할 때는 "확인 필요"로 두면 됨.

5. 판정 기준과 성능

과거 담당자 기록 1,071건을 재료로 원인 분류 10종·처리 상태 5종·유관 부서 배정 기준을 정리한 뒤, 기준 작성 때 보지 않은 55건으로 검증한 결과.

7. 문제가 생겼을 때

증상원인·대응
"Claude Code가 설치되어 있지 않습니다"Claude Code 설치 후 한 번 로그인하고 다시 실행
"판정할 불만족 건 없음"파일에 불만족(down) 행이 없는 경우. 원본을 그대로 업로드하면 됨
"필수 컬럼 누락"헤더가 대시보드 업로드 형식(query·summary_text·rating·created_at)과 다른 경우. 대시보드에 올릴 수 있는 파일이면 그대로 통과
"결과 파일이 만들어지지 않았습니다"검은 창의 메시지를 캡처해 AI 전략팀에 전달
"Node 실행 파일이 없습니다" 또는 exe가 바로 닫힘exe 파일이 손상된 경우. AI 전략팀에 exe를 다시 요청
