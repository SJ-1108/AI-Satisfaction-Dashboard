불만족 피드백 자동 판정 운영 안내

대상AI 답변 만족도 대시보드 등록 담당자
적용일2026-11-09 (대시보드 main 배포 완료)
변경 요지Metabase 파일을 올리기 전에 판정 한 번 거치면 불만족 건 피드백이 자동으로 같이 저장됨

1. 무엇이 달라지는지

지금까지는 Metabase 내보내기 파일을 대시보드에 올린 뒤, 불만족 건마다 사람이 원인 분류·유관 부서·처리 상태·피드백 내용을 직접 입력하는 방식.

앞으로는 올리기 전에 판정 단계 하나를 거침. 판정 결과가 붙은 파일을 기존과 같은 업로드 버튼으로 올리면 평가 원본과 피드백이 한 번에 저장됨. 명확한 건은 자동 확정, 애매한 건은 초안만 채워 두고 담당자가 확인.

  • 외부 유료 API 호출 없음. 판정은 Claude Code 세션 안에서 실행
  • DB 변경 없음. 대시보드 코드 배포만으로 적용 완료
  • 이미 피드백이 있는 건은 덮어쓰지 않음. 같은 파일을 다시 올려도 안전
  • 판정 열이 없는 파일을 올리면 예전과 완전히 동일하게 동작

2. 최초 1회 준비

  • 대시보드 레포 SJ-1108/AI-Satisfaction-Dashboard main 브랜치를 내 PC에 받기 (이미 있으면 git pull)
  • 레포 루트에서 npm install 한 번 (판정 도구가 쓰는 엑셀 패키지 포함)
  • Claude Code 설치. 레포 루트 폴더에서 실행하면 /판정 명령이 자동으로 인식됨

3. 매회 절차

1
Metabase에서 내보내기 파일 다운로드기존과 동일
2
레포 루트에서 Claude Code 실행 후 명령 입력 추가되는 단계 
/판정 D:\경로\metabase_2026-11-16.xlsx
불만족 행만 골라 판정. 50건 기준 10~15분. 끝나면 결과 파일 경로와 확인 필요 건 목록을 보고함
3
결과 파일 확인 tools/judge/output/metabase_2026-11-16_판정.xlsx 첫 시트 업로드 = 원본 행 전체 + 판정 열 7개. 나머지 시트는 참고용(확인필요 2단 초안, 자동확정 1단 요약)
4
대시보드 데이터 조회 → 업로드 → 결과 파일 선택 → 업로드 미리보기에 "피드백 포함 N"이 보이면 정상. 완료 메시지에 "피드백 N건 등록" 표시
5
불만족 평가 관리 → 판정 필터 확인 필요 → 건별로 열어 초안 확인·수정 후 저장 저장하면 "확인 필요" 표시가 사라지고 담당자명으로 바뀜. 자동 확정(1단) 건은 손댈 필요 없음

4. 대시보드에서 보이는 것

표시의미담당자가 할 일
자동 1단규칙상 명확한 건. 학습과 무관한 질의, 의도 판단 불가, 답변·서비스 범위 벗어남, 자료 부재가 명확한 데이터 없음. 유관 부서 없음없음
확인 필요2단 건. 원인 분류·부서·상태·피드백 내용 초안이 채워져 있고 담당자 확인 전. 모달 상단에 확인 포인트 표시초안 확인·수정 후 저장
담당자명사람이 직접 작성했거나, 2단을 확인·저장한 건없음
판정 필터전체 / 확인 필요 / 자동 확정(1단) / 자동 판정 전체 / 수동 작성"확인 필요"로 놓고 작업

판정 표시는 피드백 테이블의 상세 사유 열에 [자동판정] 단계=2단; 확신도=0.55; 확인필요=1 형식으로 저장. 화면에서 편집하지 않는 열이라 다른 기능 영향 없음.
