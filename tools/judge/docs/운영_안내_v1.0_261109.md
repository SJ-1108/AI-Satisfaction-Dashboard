# 불만족 평가 피드백 자동 판정 운영 안내 v1.0

대시보드 등록 담당자가 매일(또는 매주) Metabase 내보내기를 대시보드에 올리는 과정 사이에 판정 단계 하나를 끼워 넣는 방법. 외부 API 호출 없이 Claude Code 세션 안에서 판정하므로 비용과 서버 작업 없음. DB 변경도 없음.

## 흐름 한눈에

```
Metabase 내보내기(CSV/XLSX)
   → 레포 루트에서 Claude Code 실행, /판정 <파일>       ← 추가되는 단계 (10~15분)
   → tools/judge/output/<파일명>_판정.xlsx 생성          (원본 행 + 판정 컬럼)
   → 대시보드 [데이터 조회] 업로드에 이 파일을 올림       (기존과 동일한 버튼)
   → 평가 원본 적재 + 불만족 건 피드백 동시 저장
   → [불만족 관리]에서 "확인 필요" 건만 담당자가 열어 확정
```

## 준비 (최초 1회)

- 이 레포(`AI-Satisfaction-Dashboard`)를 로컬에 받고 루트에서 `npm install` (판정 도구가 쓰는 `xlsx` 패키지 포함)
- Claude Code 설치. 레포 루트 폴더에서 실행하면 `/판정` 명령이 자동으로 잡힘(`.claude/skills/판정`)

## 매회 절차

1. Metabase에서 내보내기 파일 다운로드 (기존 방식 그대로)
2. 레포 루트에서 Claude Code 실행 후 명령 입력
   ```
   /판정 D:\경로\metabase_2026-11-16.xlsx
   ```
3. 결과 파일 `tools/judge/output/metabase_2026-11-16_판정.xlsx` 확인
   - 첫 시트 `업로드`: 원본 행 전체 + 판정 컬럼. 이 파일을 대시보드 데이터 업로드에 그대로 올림
   - `확인필요(2단)` 시트: 담당자가 한 번 더 판단할 건의 초안·확신도·확인 포인트
   - `자동확정(1단)` 시트: 자동 확정 건 요약
4. 대시보드 [데이터 조회] → 업로드 → 결과 파일 선택. 미리보기에 "피드백 포함 N"이 보이면 정상. 업로드 완료 메시지에 "피드백 N건 등록" 표시
5. [불만족 관리] → 판정 필터 "확인 필요" → 건별로 열어 초안을 확인·수정 후 저장. 저장하면 "확인 필요" 표시가 사라지고 담당자명으로 바뀜

## 대시보드에서 보이는 것

| 표시 | 의미 |
|---|---|
| 담당자명 칸 `자동 1단` | 자동 확정 건. 학습 무관·의도 판단 불가·범위 벗어남·자료 부재가 명확한 데이터 없음. 유관 부서 없음 |
| 담당자명 칸 `확인 필요` | 2단 건. 초안은 채워져 있고 담당자 확인 전. 모달 상단에 확인 포인트 표시 |
| 담당자명 | 사람이 작성했거나 2단을 확인·저장한 건 |
| 판정 필터 | 전체 / 확인 필요 / 자동 확정(1단) / 자동 판정 전체 / 수동 작성 |

- 이미 피드백이 있는 건은 업로드 시 덮어쓰지 않음(사람 기록 보존). 같은 파일을 다시 올려도 안전
- 판정 컬럼이 없는 파일을 올리면 기존과 완전히 동일하게 동작
- 판정 표시는 피드백 테이블의 `detail_reason` 열에 `[자동판정] 단계=2단; 확신도=0.55; 확인필요=1` 형식으로 저장됨. 화면에서 편집하지 않는 열이라 다른 기능에 영향 없음

## 소요·성능 기준

- 주간 50건 기준 세션 소요 약 10~15분
- 검증(새 55건 기준): 처리 상태 일치 67%, 원인 분류 일치 49%(사람 간 일치 51%), 1단 처리 상태·부서 일치 17/20

## 판정 기준 수정

- 원인 분류 정의·단계 규칙: `tools/judge/prompts/불만족_피드백_판정_프롬프트_v1.1.md`
- 참조 가능한 데이터 범위(강의 검색 등 신규 기능 반영): `tools/judge/docs/참조데이터범위_v1.0_261109.md`
- 부서 추가·변경: `tools/judge/docs/유관부서_배정기준_v1.0_261109.md` (`lib/departments.ts` 목록과 맞출 것)
- 수정 후 별도 작업 없이 다음 `/판정` 실행 시 자동 반영. 수정 전 파일은 `archive/`에 보관하고 버전 번호 올림

## 문제 발생 시

- "판정할 불만족 건 없음": 파일에 rating=down 행이 없는 경우
- "필수 컬럼 누락": 파일 헤더가 대시보드 업로드 형식(query·summary_text·rating·created_at)과 다른 경우. 대시보드에 올릴 수 있는 파일이면 그대로 통과
- "검증 실패": 허용되지 않는 분류값·부서명·종결 어미가 있는 경우로 명령이 스스로 고쳐 재실행. 반복되면 해당 No.를 AI 전략팀 담당자에게 전달
- 업로드 미리보기에 "피드백 포함"이 안 보이면 첫 시트가 `업로드` 시트인지 확인
