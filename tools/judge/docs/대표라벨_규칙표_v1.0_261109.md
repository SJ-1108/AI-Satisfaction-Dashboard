# 처리 불가 군 하위 유형 대표 라벨 규칙표

적용 대상: 유관 부서 없이 처리 불가로 끝나는 질의. 과거 기록에서 담당자마다 라벨이 갈리던 하위 유형에 대표 라벨을 하나씩 정함. 근거는 1,071건 기록의 다수 라벨이며, 동률이거나 근거가 약한 줄은 선택 이유를 적음.

| 강사 비교·타수·순위 | 답변/서비스 범위 벗어남 | 16건 중 7 | 가드레일 정책(instructor_comparison)으로 막는 영역 |
| 강사 나이·논란·사생활·신상 | 답변/서비스 범위 벗어남 | 17건 중 4(기타 4 동률) | 자사 강사 관련이라 학습과 무관은 아니고, 기타는 분류 포기 라벨이라 피함. 강사 프로필 외 개인정보 미제공 정책과 같은 축 |

## 경계 기준
- 학습과 무관한 질의 ↔ 답변/서비스 범위 벗어남: 학습·교육·자사 서비스와 조금이라도 닿아 있으면 범위 벗어남, 전혀 닿지 않으면 학습과 무관
- 데이터 없음 ↔ 답변/서비스 범위 벗어남: 학습·입시·자사 서비스 질의인데 자료가 없으면 데이터 없음, 서비스가 다루지 않기로 한 영역이면 범위 벗어남
- 질의어 의도 판단 불가 ↔ 데이터 없음: 무엇을 묻는지 특정되면 데이터 없음, 특정 자체가 안 되면 의도 판단 불가

## 1단 자동 확정 대상(2026-11-09 확정)
- 학습과 무관한 질의, 질의어 의도 판단 불가, 답변/서비스 범위 벗어남 전 유형
- 데이터 없음 중 대학 상세 정보, 과거 연도 시험 자료, 미개설 강좌·미등록 콘텐츠처럼 자료 부재가 명확한 건
- 처리 상태는 건별 판단. 기본 처리 불가, 자료 추가 가능성이 구체적이면 보류

## 1단에서 제외(항상 2단)
- off_topic으로 차단된 질의가 교과(국어·수학·영어·사회·과학·한국사) 개념어, 역사·시사 용어, 작품명일 가능성이 있는 건: 학습 개념어 오차단이면 AI 개발 이슈(마이스). 잡담·연예·음식·비속어·외국어 문장처럼 학습과 전혀 무관한 것만 1단(No. 948, 1052, 1013)
- 올해 모의고사·수능의 난이도·등급컷·총평·정답·해설 질의: 풀서비스 데이터가 있는 영역이라 답변이 데이터를 제대로 썼는지 사람이 재검색으로 확인(No. 931, 1031)
- 타사·경쟁사·러셀 강사나 교재 질의, 강사 개인정보·강사 비교 질의인데 가드레일 라벨이 safe이거나 비어 있는 건: 걸려야 할 가드레일이 작동하지 않은 것일 수 있어 AI 개발 이슈(마이스) 여부를 사람이 확인(No. 835, 880, 522, 452)
- 특정 대학의 전형·모집요강·시험 범위 등 입시 정보 질의: 입시서비스팀·입시컨텐츠팀 보완 요청 여부를 사람이 판단(No. 859)
- 제2외국어·영단어 뜻 질의: 단순 어휘 답변 허용 여부가 정책 검토 중(No. 820, 1070)이고, 강의 데이터에 해당 단어가 있는데 미참조인 경우(AI 개발 이슈, No. 854)와 구분이 필요
- 가드레일이 걸렸는데 답변이 노출됐거나, 답변 끊김·수식 깨짐이 보이는 건
- 학생 의견이 달린 건
- 같은 질의어가 과거에 다른 원인으로 분류된 적이 있는 건
