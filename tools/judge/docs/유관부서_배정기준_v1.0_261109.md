## 3. 복수 부서 지정 규칙
- 데이터 보완 주체(문서 담당 팀)와 엔진 수정 주체(마이스)가 둘 다 필요하면 둘 다 지정. 예: 문서는 있으나 참조 안 됨 + 문서 내용도 부족(No. 593, 273, 3건 이상)
- 피드백 본문에 "(마이스)", "(학습지원팀)"처럼 부서별 요청 사항을 괄호로 구분해 적는 관행(No. 417, 383, 301, 110)
- 전 과목 공통 요청(강사 학력 데이터, 강사 특징 데이터)은 컨텐츠기획 1·2·3팀 + 고12컨텐츠기획팀 일괄 지정(No. 106, 86)

## 4. 부서를 지정하지 않는 경우
- 학습과 무관한 질의, 질의어 의도 판단 불가, 타사·경쟁사·러셀 강사 등 서비스 범위 밖 질의
- 참조 데이터 자체가 없고 추가 계획도 없는 질의(과거 연도 풀서비스·모의고사, 학과별 진출 분야, 대학 상세 정보)
- 가드레일이 정책대로 작동한 건(강사 비교, 강사 개인정보, 비속어, 경쟁사 언급)
- 예외: 위 유형이라도 가드레일이 오작동했거나 답변 생성 오류가 겹치면 마이스 지정 후 검토중(No. 970, 820, 522, 475, 452)
