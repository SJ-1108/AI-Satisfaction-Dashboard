# 불만족 평가 피드백 자동분류 변경 이력

버전 규칙: 판정 기준(프롬프트·참조 문서)이 바뀌면 가운데 자리, 실행 방식·화면만 바뀌면 끝자리를 올린다. 결과 파일 "정보" 시트에 실행한 자동분류 버전이 남는다.

## 1.2.0 (2026-11-11)
- 프롬프트 v1.2: 올해 모의고사·수능 총평·해설강의 질의에 "제공 중" 안내만 한 답변은 정책(풀서비스 페이지 링크 오노출 금지)상 정상 답변. AI 개발 이슈로 분류하지 않고, 보완 의견은 기능 개선 + "풀서비스 페이지 안내 문구 추가 제안"으로 기록(담당자 피드백 반영)
- 단일 실행 파일 배포: `불만족평가_피드백_자동분류_v1.2.0.exe`(프롬프트·스크립트·Node 실행 파일·xlsx 패키지·Claude Code 명령 내장, 설치 불필요). 더블클릭해 파일을 고르거나 아이콘 위로 끌어다 놓기. `판정_실행.bat`은 삭제
- 결과 파일에 "정보" 시트 추가(자동분류 버전·프롬프트 파일·원본 파일·실행 시각)
- 결과 파일을 원본 파일이 있던 폴더에도 복사
- 처음 실행 시 `%LOCALAPPDATA%\FeedbackJudge\v<버전>`에 풀려 그 폴더에서 Claude Code 실행(영문 경로로 둔 이유: 한글 경로에서 Node 모듈 로드가 크래시). 내장 Node v24.15.0
