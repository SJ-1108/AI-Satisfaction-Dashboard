# 판정기 변경 이력

버전 규칙: 판정 기준(프롬프트·참조 문서)이 바뀌면 가운데 자리, 실행 방식·화면만 바뀌면 끝자리를 올린다. 결과 파일 "정보" 시트에 실행한 판정기 버전이 남는다.

## 1.2.0 (2026-11-11)
- 프롬프트 v1.2: 올해 모의고사·수능 총평·해설강의 질의에 "제공 중" 안내만 한 답변은 정책(풀서비스 페이지 링크 오노출 금지)상 정상 답변. AI 개발 이슈로 분류하지 않고, 보완 의견은 기능 개선 + "풀서비스 페이지 안내 문구 추가 제안"으로 기록(담당자 피드백 반영)
- 배포 패키지 도입: `판정기_v1.2.0.zip`(Node 실행 파일·xlsx 패키지 포함). 압축 해제 후 `판정기.bat`에 파일을 끌어다 놓거나 더블클릭해 파일 선택
- 결과 파일에 "정보" 시트 추가(판정기 버전·프롬프트 파일·원본 파일·실행 시각)
- 결과 파일을 원본 파일이 있던 폴더에도 복사
